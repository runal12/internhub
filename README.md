# Internship Portal

A simple internship portal with a sign up form, user list, and basic About/Contact pages.

## Scripts

- `npm start`: start the development server
- `npm run build`: create a production build

## Structure

- `src/components`: UI components like `Navbar`, `SignUpForm`, `UserCard`
- `src/pages`: simple pages (`About`, `Contact`)
- `src/App.js`: app shell and navigation

## Notes

This project is a lightweight demo focused on UI/UX. No backend is included.
